# AttendX-Test-Scripts

## Project Overview
This repository contains sample test scripts for the AttendX student attendance application.

## Files
- `login_test.py`: Demonstrates valid login input and empty username test scenarios.
- `attendance_test.py`: Demonstrates attendance input validation and empty student ID test scenarios.

## Technologies
- Python
- Git
- GitHub
- Visual Studio Code

## Purpose
Git and GitHub are used to track changes, preserve commit history and support collaboration among QA engineers.

## Note
These are demonstration validation scripts. They do not connect to a live attendance application.
